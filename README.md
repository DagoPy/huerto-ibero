# Planeador de Huerto Biointensivo

Aplicación web para planear la siembra de un huerto usando el método biointensivo
(basado en *Cómo cultivar más vegetales*, de John Jeavons).

Eliges las hortalizas, fijas la fecha de trasplante a la cama de siembra y la aplicación
calcula el resto del calendario: composta, almácigos, preparación de la cama y cosecha.
